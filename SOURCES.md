# SOURCES — Vélocité Motors

Traçabilité des ressources utilisées. Toutes les photographies proviennent d'Unsplash (licence Unsplash, usage commercial autorisé, attribution non requise mais mentionnée). Les images ont été recadrées, redimensionnées et converties en WebP ; les emblèmes et plaques d'immatriculation visibles ont été floutés.

Les logos (Vélocité Motors, Aurelis, Borgvik, Tessari) sont des **créations originales** en SVG, réalisées par Matrice Studio pour cette démonstration — ils ne s'inspirent d'aucun logo existant.

## Icônes UI

Toutes les petites icônes (chevrons, coches, pictogrammes services) sont des **SVG inline dessinés pour ce projet** (tratis 1.6–1.8 px), aucun emoji n'est utilisé.

## Outils

- Traitement d'images : scripts Python/PIL locaux (`_scripts/` hors livrable).
- Favicons : script PIL (`_scripts/make_favicons.py`).
- Assemblage des pages : `node _scripts/build.js` (partials `src/pages/` → pages racine).
